# Лабораторная работа №2

Виртуальный датчик для контроля процесса обжига в печи.

В [ноутбуке](lab2_virtual_sensor.ipynb) находятся весь код, графики и выводы.
Краткое описание результатов — в [отчёте](report.md).

## Файлы

```text
data/                       четыре исходных CSV
results/                    метрики и прогнозы
lab2_virtual_sensor.ipynb    основная работа
report.md                   краткий отчёт
requirements.txt            библиотеки
README.md                   инструкция
```

## Запуск

Нужен Python 3.11–3.13. Проверено на Python 3.13.
Из папки проекта выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m jupyterlab lab2_virtual_sensor.ipynb
```

В Jupyter выберите ядро созданного окружения и запустите все ячейки по порядку.
Исходные данные уже лежат в `data`. По завершении обновятся три CSV в `results`:
метрики, прогнозы в моменты анализов и поминутный прогноз.

## Результат

Сравниваются Ridge, ExtraTrees и градиентный бустинг. Дополнительно используются
две обычные линейные модели OLS, медиана и последний известный анализ.
Основная модель выбирается по проверке на более поздних периодах train.

У ExtraTrees MAE на тесте около **0.074**, у последнего доступного анализа —
**0.0595**. Поэтому модель пока не лучше этого простого способа по точности уровня.
Все результаты оставлены в отчёте, в том числе неудачные.

Чем меньше MAE, RMSE, MAPE и WAPE, тем лучше. DA показывает долю верных направлений
изменения. MAE и RMSE выражены в единицах CSV; физическая шкала концентрации
не указана. Время target считается временем отбора пробы, а ответ доступен через
15 минут. Это допущение подробно разобрано в ноутбуке.
