# Отчёт по лабораторной работе №2

## 1. Что было в данных

Задача — оценить концентрацию продукта по показаниям датчиков печи.
В обучающей телеметрии после удаления повторов 317,998 минут, лабораторных
анализов 1773. Обычно анализы идут через 120 минут,
но есть большие перерывы. Один анализ находится позже конца обучающей телеметрии,
поэтому я его исключил. Данные из test для его заполнения не брал.

У четырёх каналов измерения появляются примерно раз в два часа. Их пропуски
нельзя просто заменить нулями. Есть и длинные постоянные участки показаний.
По графикам заметны изменения режима и уровня target, а сильной устойчивой
суточной сезонности не видно. Крайние значения я не удалял: они могут быть связаны
с изменением процесса.

## 2. Как подготовлены признаки

Время target считаю временем отбора пробы, а анализ доступен через 15 минут.
Это допущение, так как пояснения к временным меткам нет. Для редких каналов также
добавил 15 минут до доступности. Последнее минутное значение переношу максимум
на 5 минут, редкое — на 240 минут. Добавил возраст показаний.

Использовал лаги 1–120 минут, среднее, стандартное отклонение, минимум и максимум
за 15/60/180 минут, скорости и темпы изменения, признаки пропусков и времени.
Оконные статистики заканчиваются в предыдущую минуту. Получилось 420
признаков, из них для основных моделей отбираются 64. Все обучаемые преобразования
считаются только по соответствующей обучающей части. PCA не использовал, чтобы
сохранить понятные названия признаков.

## 3. Какие модели сравнивались

Ridge выбрана как простая регуляризованная линейная модель, ExtraTrees и бустинг —
для нелинейных зависимостей. Дополнительно посчитал две OLS, медиану и последний
известный анализ. Для выбора основной модели использовал три проверки по времени.
Последние 15% обучающих проб оставил на отдельную валидацию. Между обучением и
проверкой — 195 минут. В итоге по средней ошибке CV выбрана ExtraTrees
(MAE 0.07166). Её параметры на тесте не менял.

Классификатор для непрерывного target не подходит. Модели с будущими показаниями
дают утечку. Обычная ARIMA/ETS без учёта нерегулярного шага анализов также некорректна;
большие нейросети пока не использовал из-за небольшого числа размеченных примеров.

## 4. Что получилось

| Модель | MAE | RMSE | MAPE, % | WAPE, % | DA, % |
| --- | --- | --- | --- | --- | --- |
| Ridge | 0.07746 | 0.09039 | 47.05 | 36.94 | 57.2 |
| ExtraTrees | 0.07397 | 0.08782 | 44.78 | 35.28 | 53.5 |
| Бустинг | 0.08076 | 0.09538 | 48.82 | 38.51 | 50.8 |
| OLS без лагов | 0.06934 | 0.08459 | 41.01 | 33.07 | 56.5 |
| OLS с динамикой | 0.06793 | 0.08384 | 40.01 | 32.39 | 60.2 |
| Медиана | 0.08218 | 0.09362 | 49.83 | 39.19 | 0.0 |
| Последний анализ | 0.05949 | 0.08006 | 29.72 | 28.37 | 35.1 |


Основная модель ExtraTrees уступает последнему уже известному анализу по MAE:
0.07397 против 0.05949. При этом направления изменений
совпадают в 53.5% случаев против 35.1%
у последнего анализа. MAPE посчитана без нулевых target; на тесте для неё
318 точек. Для направлений осталось 299
ненулевых переходов без разрывов более шести часов.

Тест Жарка–Бера дал p=0.000308, Льюнга–Бокса — p=3.26e-12,
Бройша–Пагана — p=4.65e-10. Остатки ненормальны, автокоррелированы, их дисперсия
не постоянна. Для Льюнга–Бокса использован регулярный участок из 144
проб с шагом два часа. AIC ниже у OLS с динамикой, BIC — у OLS без лагов.
Эти сравнения условны, поскольку предпосылки OLS выполнены не полностью.
Обучение выбранной модели заняло около 0.31 с.

Самые важные признаки: telemetry_0__min_15, telemetry_12__lag_30, telemetry_0__min_60.
Лаги и скользящие статистики согласуются с инерцией процесса. Названия физических
параметров неизвестны, поэтому конкретные причинные связи по ним не утверждаю.

## 5. Общий вывод

Получился работающий расчёт с тремя основными моделями, но преимущества по MAE
перед последним анализом нет. Заменять лабораторный контроль по этим результатам
рано. Нужны описания датчиков, точное время проб и больше данных о разных режимах.
Поминутные прогнозы сохранены для 39747 минут, однако между
анализами настоящая концентрация неизвестна. Все основные графики, дополнительные
таблицы и пояснения находятся в ноутбуке.
